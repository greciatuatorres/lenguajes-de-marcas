## 📚 Contenidos del Módulo

1. UT1. Introducción a los lenguajes de marcas.
2. UT2. XML: sintaxis, estructura y espacios de nombres.
3. UT3. Validación con DTD y XML Schema.
4. UT4. XPath: consulta y navegación de documentos.
5. UT5. XSLT: transformación de documentos.
6. UT6. Sindicación de contenidos: RSS y Atom.
7. UT7. Almacenamiento, formatos de intercambio y XQuery.
8. UT8. Sistemas empresariales: ERP y CRM.
9. UT9. HTML5: estructura, semántica y accesibilidad.
10. UT10. CSS: presentación y diseño adaptable.
11. UT11. JavaScript y manipulación del DOM.
